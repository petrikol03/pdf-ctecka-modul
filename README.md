# PDF čtečka – místní modul pro Windows

Instalační balíčky a kontrolní součty pro [českou PDF čtečku](https://pdf-ctecka-web.onrender.com/).

[Stáhnout místní modul pro Windows 64 bit](https://github.com/petrikol03/pdf-ctecka-modul/releases/download/v0.1.0/PDF-Mistni-Modul-0.1.0-Setup-x64.exe)

Po instalaci se vraťte do čtečky, otevřete Místní modul a zvolte Připojit modul. Prohlížeči případně povolte přístup k místní síti. Modul běží na pozadí bez dalšího okna čtečky a bez další ikony na ploše. Převody a OCR se zpracovávají v tomto počítači.

Instalace je pro aktuálního uživatele. Odinstalace je dostupná v nastavení aplikací Windows. Originální PDF se nepřepisují.

Instalátor zatím nemá digitální podpis vydavatele. Vedle instalačního souboru je zveřejněný SHA-256 a licenční informace.
